# Parimal Mishra — Portfolio

A static, Vercel-ready portfolio inspired by the layout language of the supplied reference site.

## Before deploying
1. Put your own 3–6 photos into the site and replace the `.photo-placeholder` blocks in `index.html` with `<img>` elements. The carousel and animation are already wired.
2. Open `script.js` and replace `SPOTIFY_PLAYLIST_URL` with your exact Spotify playlist URL. `SPOTIFY_PLAYLIST_TITLE` can be changed to the playlist name.
3. Keep `Parimal_Mishra_Resume.pdf` in the same folder if you want the Resume modal's download button to work.

## Deploy
Upload this folder to Vercel as a static site. No build command or dependency installation is required.
